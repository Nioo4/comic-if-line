# 漫画IF线

漫画IF线帮助熟悉某段漫画剧情、却对其中一个结果或过程感到遗憾的读者，把这份遗憾整理成一条尊重已确认事实和约束的 IF 因果线，并输出可阅读、可复制的六格文字分镜。

你可以从自己记得的局部剧情出发，逐步补充和确认信息，再比较几条不同走向。它关注的是一次具体的 IF 创作，不要求你先整理完整作品资料。

## 目标用户

适合熟悉某段漫画剧情、对结果或过程有遗憾，并愿意补充、核对和确认局部事实的读者。你可以明确想改变什么，也可以保留原作结果，只重写导致结果的过程。

## 功能

- 用自然语言整理背景、遗憾及原因、多个必达结果，以及可选的偏好、不可破坏设定和余韵。
- 信息不足时回答 1—3 个追问，帮助补齐当前创作需要的局部信息。
- 逐条确认事实，也可以把内容改成创作假设或删除，再继续创作。
- 系统先形成 5 个内部方向并进行审查，再展示 1—3 个候选路径。
- 选择一条路径后生成固定六格文字分镜：张力、分歧、选择、行动与代价、改变后的结果和情绪余韵。
- 结果页展示目标覆盖、事实依据、创作假设和需要留意的警告。
- 会话可以恢复；也可以清除本次会话，从空白状态重新开始。

## 本地运行

需要 Node.js 24.x、npm，以及可用的 DeepSeek 兼容 API key 和 base URL。

```bash
git clone https://github.com/Nioo4/comic-if-line.git
cd comic-if-line
npm ci
cp .env.example .env.local
```

编辑 `.env.local`，填写以下四项：

```text
DEEPSEEK_API_KEY=填写你的API key
DEEPSEEK_BASE_URL=填写DeepSeek兼容服务地址
AI_CALL_TIMEOUT_MS=180000
MAX_REQUEST_BYTES=100000
```

然后启动：

```bash
npm run dev
```

打开 <http://localhost:3000> 即可使用。
